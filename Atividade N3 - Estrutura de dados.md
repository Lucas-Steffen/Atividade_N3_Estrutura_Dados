# Atividade N3 - Estrutura de Dados e Organização de Arquivos

## Para a Atividade
Para a atividade avaliativa da disciplina o acadêmico deverá unir todos os conceitos trabalhados em sala e criar um programa que contemple os seguintes requisitos:

1. Sistema de cadastro que deve ter as funções de `incluir`, `alterar`, `excluir`.
2. Persistência de dados em `json`
3. Pesquisa por campos do tipo `texto`
4. Impressão de listas ordenadas por 2 campos diferentes.

## Como fazer
- Utilizem a linguagem python
- Todas as operações do trabalho foram exemplos passados em sala.

## Composição da nota
A Nota N3 será composta seguindo o padrão de notas 3.0 e 7.0, sendo que:
